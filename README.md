# Movie-Recommender-System
Developed a movie recommendation system leveraging collaborative filtering and content-based filtering techniques.
 Utilized user interaction data and movie metadata to provide personalized recommendations. Implemented algorithms
 using Python, with tools such as Pandas, NumPy, and Scikit-Learn, and employed matrix factorization for enhancing
 recommendation accuracy. Integrated the system with a user interface, ensuring a seamless user experience and
 scalability.
 • TechStack: Python, Numpy, Pandas, Scikit-Learn, Jupyter Notebook
